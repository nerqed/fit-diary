# История изменений Forma

## 0.1.1 — в работе — 14 ноября 2026

- Исправляется проверка архитектуры готового приложения: путь к бинарнику должен предшествовать списку архитектур в `lipo`.
- Повторный выпуск использует новый тег; история первой попытки сохранена.

## 0.1.0 — исходники, без опубликованного IPA — 14 ноября 2026

### Выполнено
- Создан закрытый репозиторий `nerqed/fit-diary`, без доски Projects.
- Подготовлены правила этапов, границы дизайнера и документация для установки с iPhone.
- Добавлены пять вкладок, отдельный профиль, типизированные контракты и демонстрационные данные.
- Логика и навигация отделены от заглушек экранов; папки дизайнера сохранены для его работы.
- Имена нативного приложения зафиксированы как Forma, отображаемое имя — «Форма».
- Подготовлен выпуск unsigned IPA через GitHub Actions по тегу или вручную, с проверкой архива и публикацией в Releases.

### Проверки
- TypeScript, совместимость зависимостей Expo и Expo Doctor (20/20) прошли.
- Экспорт iOS JavaScript прошёл: встроенный Hermes-бандл и 16 ресурсов навигации.
- Проверена структура экранов; исправлен нижний безопасный отступ отдельного профиля.
- Установка через E Sign и запуск на iPhone пока не проверены.
- Нативный Release archive успешно собран в GitHub Actions. Проверка `lipo` остановилась из-за порядка аргументов; IPA не опубликован. Исправление выпускается как 0.1.1.

### Ограничения версии
- Только навигационный каркас и демонстрационные данные.
- Дизайн выполняется отдельным разработчиком.
- Реальный дневник, тренировки, камера, ИИ, уведомления и облачная синхронизация не входят в этап 1.
