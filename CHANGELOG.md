# История изменений Forma

## 0.3.0 — тренировки и прогресс · 24 ноября 2026

- Вкладки «Тренировки» и «Прогресс» работают с локальной SQLite через `openWorkoutController`. Шаблоны можно создавать, редактировать, копировать, удалять и запускать. Повтор прошлого занятия использует сохранённый состав даже после удаления шаблона.
- В конструкторе есть встроенные и собственные упражнения, порядок упражнений и подходов, план повторений и необязательный вес. На занятии предложенные значения подтверждаются одной галочкой. Пустой вес, нулевая внешняя нагрузка и собственный вес отображаются раздельно.
- Если в прошлый раз выполнены все плановые повторения, прибавка составляет 2,5 кг, для гантелей — 1 кг. При включённом RIR прибавка требует минимум двух повторений в запасе во всех подходах. При недоборе или неизвестном RIR сохраняется прежний записанный вес. Заметки к упражнениям и RIR включаются в «Профиль → Дополнительно».
- После отметки подхода появляется плашка отдыха на 90 секунд с командами «+15 с» и «Пропустить». Дедлайн хранится в базе. Когда приложение активно, окончание сопровождается тактильным сигналом.
- В итоге занятия видны выполненные подходы, объём внешней нагрузки и новые личные рекорды. Сравнение веса ведётся при одинаковом числе повторений. Первый известный результат устанавливает рекорд, повтор того же результата сохраняет прежний. При неполном весе показывается известная часть объёма.
- Календарь открывает занятия за выбранный день. Прошлую тренировку можно добавить или дополнить во время сегодняшнего занятия. История, подсказки и рекорды пересчитываются. График веса тела показывает измерения и среднее за семь календарных дней по имеющимся записям. Изменение за неделю сравнивает два соседних семидневных окна.
- Экспорт и восстановление через «Файлы» включают вес, настройки, RIR и заметки. Приложение читает копии v1, проверяет выбранный файл и создаёт отдельную проверенную копию текущих данных до восстановления.
- На вкладках остался один крупный заголовок. Профиль открывается кнопкой с символом `person.crop.circle`, замена упражнения — кнопкой с `arrow.triangle.2.circlepath`. Обе доступны VoiceOver. Даты и единицы локализованы. Для SDK 58 закреплены `expo-haptics@58.0.8` и `react-native-svg@15.16.0`.

Отдельно проверены экран импорта, отмена, повреждённый файл и отказ записи страховочной копии. Нативные компоненты в этих проверках заменены тестовыми.

## MVP-1 — логика тренировок, без нового IPA — 17 ноября 2026

- Приоритет изменён: тренировки → рабочие экраны дизайнера → релиз/проверка → питание. XP, задачи дня, стрик, достижения и coachHint отложены до после MVP. Предыдущая дорожная карта сохранена в docs/ROADMAP-pre-MVP.md.
- Добавлены SQLite-схема с миграциями, очередь операций, 36 русских упражнений, собственные упражнения, CRUD/копирование шаблонов, снимки сессий, фактические подходы и сохранение deadline отдыха.
- Добавлены история упражнения, предыдущие подходы, график веса при фиксированных повторениях, объём с полнотой данных и личные рекорды.
- Реализованы полный JSON-экспорт данных MVP-1, проверка импорта, постоянная резервная копия перед заменой и атомарное восстановление без дублей. Подготовлены нативные адаптеры выбора/экспорта файлов и обновление контроллера после восстановления.
- Добавлены рабочие контракты и инструкция подключения дизайнеру; для питания — только будущий контракт редактора/справочника/адаптера/очереди. MVP-2 не реализовывался.
- Закреплены совместимые зависимости Expo SDK 58: sqlite 58.0.17, document-picker 58.0.5, file-system 58.0.13, sharing 58.0.23, crypto 58.0.8; tsx 4.23.15 для тестов.
- TypeScript приложения и тестов прошёл. 29 тестов прошли, включая настоящую SQLite через node:sqlite. В будущий Linux preflight выпуска добавлен запуск тестов; macOS на обычные коммиты не запускается.
- src/screens/ и src/theme/ не изменены. Текущие экраны продолжают показывать моки. Нативные операции нового слоя на iPhone не проверены; тег/релиз/IPA не создавались, версия остаётся 0.1.1.

## Этап 1.1 — без нового релиза — 16 ноября 2026

- Расширены контракты данных и действий для всех шести экранов: питание, нутриенты, тренировки, история для графиков, состояния чата и типизированный профиль с редактируемыми параметрами нормы.
- Моки содержат четыре приёма пищи, шесть блюд, пять упражнений и 28 нутриентов. Добавлены все способы ввода, все источники включая `store`, фото-заглушка без сети, нулевые/неизвестные и приблизительные значения, план/факт подходов, четыре состояния помощника, пустой и заполненный демонстрационные профили.
- Итоги моков считаются из блюд. Полное значение остаётся `null` при пропусках, известная часть вынесена в `knownAmount`, полнота — в `coverage`; день содержит счётчики покрытия нутриентов данными.
- Контейнеры передают новые данные и callbacks. Действия явно сообщают, что это демонстрация и данные не сохранены. В заглушках экранов изменена только строка вывода `exercise.id/name` в WorkoutsScreen для совместимости типов.
- Добавлена зависимость `expo-symbols@58.0.5` для Expo SDK 58. Навигация читает `src/theme/tabIcons.ts`; все пять иконок оставлены пустыми для дизайнера.
- ROADMAP дополнен правилами ручного/текстового/фото-ввода, детерминированных расчётов, внутреннего календаря, сводки за вчера в 07:00, необязательных каталогов магазинов на VPS, веб-поиска и тестовой проверки HealthKit после этапа 7.
- README использует нейтральную формулировку о доступе к репозиторию и описывает границы работы дизайнера.
- До передачи экранов выпуск заморожен: версия приложения остаётся 0.1.1, тег, IPA и GitHub Release не создаются.
- Единственная выполненная проверка — `npm run typecheck`, успешно. Нативная сборка, экспорт, тесты и остальные проверки не запускались; работа нового модуля иконок на устройстве пока не проверена.

## Установка подтверждена — 14 ноября 2026

- Владелец сообщил: E Sign 5.0.2 успешно подписывает и упаковывает v0.1.1, но кнопка установки не вызывает системного окна. Другие приложения с этим сертификатом недавно устанавливались.
- В настройках E Sign был выбран адрес установки Server. После переключения на Local началась установка; владелец подтвердил её завершение и открытие «Формы» с вкладками. Сбой серверного маршрута устранён сменой способа установки; состояние внешнего сервера и сертификата отдельно не диагностировалось.
- Скачан опубликованный исходный IPA; SHA-256 совпал с релизом. Проверены основной Mach-O и восемь встроенных frameworks: arm64, платформа iOS, все объявленные встроенные зависимости присутствуют. Минимальная версия приложения — iOS 16.4.
- В журнале подписи замечено понижение минимальной iOS до 10.0. README уточнён: для целевого телефона менять совместимость не требуется. Причиной текущего симптома эта настройка не признана.
- Подписанный файл отдельно не анализировался; успешные установка и запуск подтверждены владельцем. Переходы между всеми экранами и повторный запуск в авиарежиме ещё не подтверждены.
- README дополнен проверенным способом установки Local. Исходники приложения и опубликованный IPA не изменены; новая macOS-сборка не запускалась.

- Создан закрытый репозиторий `nerqed/fit-diary`, без доски Projects.
- Подготовлены правила этапов, границы дизайнера и документация для установки с iPhone.
