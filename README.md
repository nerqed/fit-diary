# Форма / Forma

Личное приложение на русском для iPhone: питание, тренировки и прогресс. Сейчас реализуется **этап 1: технический каркас с демонстрационными данными**. Визуальное оформление выполняет отдельный разработчик.

## Скачать и установить — только с iPhone

Компьютер, Xcode и Expo Go вам не нужны.

1. Откройте [GitHub Releases](https://github.com/nerqed/fit-diary/releases) в **Safari** и войдите в GitHub под аккаунтом, которому доступен этот закрытый репозиторий.
2. Откройте нужную версию и раздел **Assets**. Скачайте файл `Forma-v…-unsigned.ipa`, а не архив `Source code`.
3. Найдите скачанный IPA в приложении **«Файлы»**, обычно в папке «Загрузки».
4. Импортируйте скачанный файл в **E Sign** через выбор файла или меню «Поделиться».
5. В E Sign выберите свой действующий сертификат и совместимый профиль, подпишите приложение вместе с вложенными библиотеками и установите его.
6. Запустите **«Форма»**. При обновлениях сохраняйте bundle ID и совместимую идентичность подписи.

Названия кнопок E Sign могут отличаться между версиями. Сертификат и пароль к нему остаются у вас: репозиторий и сборка их не запрашивают. Не вставляйте GitHub-токен в ссылку и не передавайте его E Sign — скачайте файл через авторизованный Safari.

SHA-256 в описании релиза относится к **исходному неподписанному IPA**. После подписи контрольная сумма изменится. Установка и срок действия подписи зависят от вашего сертификата и способа подписи.

## Что проверить в первой версии

- Установка и открытие на iPhone 15 Pro Max / iOS 26.6.1.
- Все пять вкладок: «Сегодня», «Дневник», «Тренировки», «Прогресс», «Помощник».
- Открытие профиля и возврат назад.
- Повторный запуск в авиарежиме: каркас не должен просить Metro или компьютер.
- Текст не скрывается за Dynamic Island и нижним индикатором.

Данные на экранах — примеры, не ваши записи. На этапе 1 нет сохранения дневника, камеры, ИИ, уведомлений и облака. Замечания после установки фиксируются в [ROADMAP.md](ROADMAP.md); следующие этапы начинаются только после вашего отзыва.

## Процесс разработки

- [ROADMAP.md](ROADMAP.md) — этапы, критерии и статус.
- [CHANGELOG.md](CHANGELOG.md) — изменения и фактические проверки.

- Каждая версия привязана к тегу и полному commit SHA. Опубликованный IPA не заменяется другой сборкой.

## Сборка без компьютера владельца

Выпуск полностью выполняется в GitHub Actions. Для повторного запуска существующего тега можно открыть **Actions → Release unsigned iOS → Run workflow** в браузере, выбрать основную ветку и указать существующий тег вида `v0.1.1`. Новый выпуск подготавливает разработчик.

Закреплённая среда:

| Компонент | Значение |
| --- | --- |
| Runner | `macos-26`, arm64 |
| Xcode | `26.6`, build `17F113` |
| DEVELOPER_DIR | `/Applications/Xcode_26.6.app/Contents/Developer` |
| Node.js | `22.23.4` |
| Expo | SDK 58, `expo@58.0.25` |
| Имена target/scheme/product/binary | `Forma` |
| Bundle ID | `com.nerqed.forma` |
| CFBundleDisplayName | `Форма` |

Путь: `npm ci` → `expo prebuild -p ios --no-install` → `pod install` → `xcodebuild archive` (Release, iphoneos, `CODE_SIGNING_ALLOWED=NO`) → `Payload/Forma.app` → ZIP → `.ipa`.

JS-бандл и ресурсы включаются в приложение. Metro используется как сборщик в CI, но сервер Metro не нужен при запуске установленного приложения. EAS, сертификаты, provisioning profiles и `xcodebuild -exportArchive` не используются.

Сборка запускается **только** по тегу `v*` или вручную; обычные коммиты не расходуют минуты macOS. Сначала идут проверки на Linux и проверка уже существующего релиза. Версия Xcode проверяется точно; незаметного переключения на другой Xcode нет.

GitHub обновляет содержимое образа `macos-26`: это закреплённое семейство ОС, а не неизменяемый снимок. Фактический `ImageVersion` записывается в отчёт. Доступные минуты и ограничения Actions зависят от аккаунта; бесплатность не предполагается.

## Границы для разработчиков

- `src/navigation/` — маршруты и навигация.
- `src/contracts/` — данные и действия экранов.
- `src/mocks/` — явно обозначенные примеры.
- `src/features/` — композиция и логика вне отображения.
- **`src/screens/` и `src/theme/` — зона дизайнера. Здесь только заглушки, дизайн не выполняется.**

Экраны не обращаются напрямую к базе, сети или модели. Дизайнер может заменить заглушки, сохранив экспортируемые контракты. Неизвестные сведения о владельце не заполняются догадками.

Для проверки исходников в среде разработчика: `npm ci`, `npm run typecheck`, `npx expo-doctor`, `npx expo export --platform ios --output-dir work/ios-export`. Эти действия не требуются от владельца iPhone.
